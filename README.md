# Resurrection Musical Instruments (RMI) 🎸
### A black and red-themed, luxury Management System for a musical instrument store. This application handles Inventory, Sales (POS), Analytics, Service Requests, and Appointments with a focus on a high-end user experience.

### ✨ Features
**Inventory Management: Full CRUD operations for musical gear.

Role-Based Access: Distinct permissions for Admin, Staff, and Customers.

Sales/POS System: (In Development) Interactive cart and checkout logic.

Service & Repairs: Track pending instrument services.

Responsive Design: Dark-mode luxury aesthetic using CSS variables.
**
### 🛠️ Tech Stack
Backend: PHP 7.4+ (PDO for Database security)

Database: MySQL / MariaDB

Frontend: Vanilla JS, HTML5, CSS3 (Modern Flexbox/Grid)

Fonts: Playfair Display & DM Sans
